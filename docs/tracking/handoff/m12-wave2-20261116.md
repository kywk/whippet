- Migration 026、管理 GET／PATCH API：以後端 profile 白名單選 engine／provider／model／effort／capacity，Workspace 預設 builtin，主 skill 可覆寫；API 只收 profile ID 與 revision CAS，不收 endpoint 或 key。M11 builtin/external 派工模式獨立保留。
- 排隊交易寫入有效 runtime 與固定順序 SHA256；三端以同一份 golden 測資校驗。派工／重播讀原快照，Test partial 的受控繼續沿用來源 runtime，重送仍冪等；設定變更只影響新排入的獨立任務。
- Worker 在解析非機密環境前套用快照，固定對應供應商的機密設定，缺 key 不借用；final guard 也攔截未選中供應商的 key。工具、skill pins、模型／工具／時間與 output 預算不擴張。
- 無 runtime 的歷史輸入保留既有行為，不回寫歷史資料。帶 runtime 的新輸入需協同更新 Server／Manager／Worker，舊端會拒絕；詳見 [v12 契約](../../../contracts/mvp-v12.md#m122-wave2控制面-runtime-快照)。
