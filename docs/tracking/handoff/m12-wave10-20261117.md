## 本波交付與界限

- registry13.0新增 Worker 內部 `record_conversation_memory`。在同一次模型迴圈選取已讀歷史的完整原句並分類為目標、限制、決策、進度、證據引用；Worker 核對來源 role、sequence、UTF-8 byte 位移與句界。沒有額外摘要模型或隱式歷史請求。
- user 才能提供目標／限制／決策；assistant 的進度／證據引用仍是未查核主張。事實只能合併，累計最多12項，每項最多512 bytes；不可用後次呼叫刪掉限制。保存 conversation、base/context revision、Stage、原頁 cursor／hash、fragment 範圍與完整 user 片段。
- 雙引擎壓縮舊 history 時保留該頁完整 user 片段，包含模型未選取的退款限制。當前訊息／scope／revision／Stage／證據、最新完整工具結果、call/result 配對與 opaque reasoning 維持保護。超量即拒絕，不裁掉 user 文字。
- 摘錄 JSON 沿既有 `conversationSummary` 保存，最多8192 UTF-8 bytes，`dataOnly:true`、`validationEvidence:false`。coverage 明訂最後一次成功記錄的所列頁面；後來新讀頁面需在原額度內再記錄。下一輪只把既有字串當背景 DATA，不自動匯入可信來源或授權。
- 四主 skill 僅在完整 capability／凍結 history／read 權限／client 同時成立時開工具；Server 與 Manager 各自 gate。MCP 接單工具不新增此 Worker 內部能力，既有參考 Worker 相容。新的 registry、四主 skill 與 pins 必須整體打包，歷史 Run 不重釘或改 digest。
- 來源、衍生摘要與輸出重新套用機密守衛。遮蔽改寫的頁面不能建立原文 byte 位移／hash，仍可沿原歷史讀取使用；後來辨識到的秘密不能透過衍生記憶重新帶出。取消不交付摘要 artifact 或後續候選。

原8模型／12工具／180000ms、history4次、單頁6片段／8192 bytes及原 output cap不變，受控 continue／拆分分配不變；失敗記錄也扣工具額度。沒有新依賴、migration、wire／artifact欄位或部署。精確契約見 [v12 Wave10](../../../contracts/mvp-v12.md#m121-wave10有界結構化對話記憶registry-130)。

這是有界、可核對來源的摘錄記憶，尚未宣稱任意長對話全量語意、所有 assistant 文字涵蓋、跨 Run 自動合併或任意大候選完成。句界／原文檢查可攔截否定句切片，但不能自動證明完整語意等價；保留完整 user 片段並提供原文讀回，維持這個界限。

2. 新工具最初僅驗 exact substring，可把「不得刪除斷言」截成「刪除斷言」。[red raw](../../research/evidence/m12-wave10-20261117/quote-boundary-red.txt)保留；現要求完整句界與角色來源，該案例已拒絕。另測遮蔽後位移改變的頁面不能建立失準記憶。
