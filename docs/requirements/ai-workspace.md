# AI 對話工作區規格

2026-11-12 使用者已同意；本文件定義目標行為，不表示已實作。進度只在 [實作計畫](../tracking/implementation.md) 維護。

## 對象與完成條件

不懂 Playwright 的 QA 能透過 AI 建立、修改、驗證與發佈測試；不必手寫腳本。保留 QA 明確確認發佈。本輪登入先支援帳密表單，不包含 SSO、MFA、驗證碼或人工遠端接管。

## 測試一般模式

右側依序為標題、說明、最近一次執行、歷史紀錄、歷史版本、唯讀腳本。預設說明與腳本屬目前正式版本；選擇歷史版本時清楚標示所選版本，正式執行仍使用目前發佈版本。

- 「修改腳本」進入對話編輯模式。有活躍草稿時按鈕表意為繼續修改。
- 正式執行紀錄與 AI 撰寫／草稿驗證分開；後兩者呈現在編輯對話。
- 歷史版本第一列顯示尚未發佈的「草稿」，提供續編與刪除。
- 未曾發佈的 Test 顯示尚未發佈與空狀態，不能正式執行；刪除其草稿後保留 Test，可重新開始。
- 刪除草稿須確認對話框，說明放棄本次修改與對話接續、不影響正式版本。活躍任務先取消並等終止，再完成放棄；失敗時保留草稿並可重試。歷史證據不連帶刪除。

## 新建／修改測試

整個右側為類似 ChatGPT 的對話工作區：持久訊息、輸入區、AI／排隊狀態、腳本預覽、驗證結果、唯讀監看與報告卡片。必要動作以卡片按鈕提供，不要求 QA 輸入特殊指令。離開／重開可恢復已保存內容；未送出文字與進行中操作提供離開保護。

- 新建直接進入對話；Test 名稱／說明可在對話中收斂，不以完整表單作前置門檻。
- 無草稿時，從目前正式版本建立編輯週期，提供完整腳本、版本說明與背景摘要。
- 有草稿時，接續同一編輯週期，提供草稿完整腳本、該週期對話摘要及近期訊息；完整歷史可按需取用。
- 每輪均提供 Workspace 背景與範圍快照，機密只傳引用；等待使用者時釋放 Worker。
- 驗證是真實 Run，狀態由 Server 提供；AI 文字不可代替測試通過或報告就緒。
- 通過後 AI 依實際腳本、對話及該次驗證證據，產生 description 與背景摘要，包含目的、前置條件、步驟、檢查項目及限制。兩者保存到版本，供下次 Agent 使用。
- 摘要失敗可獨立重試，不重跑未改變的成功驗證；腳本／驗測設定改變須重新驗證。QA 看過摘要及報告後明確確認發佈，AI 不自動發佈。
- 對話內修復正式失敗只更新草稿，不改寫正式版本。

## Workspace 對話設定與多工作區

支援建立、切換與修改多個 Workspace，目前均為 Superadmin。每個 Workspace 保存名稱、驗測目的、範圍／排除事項、多組網站（名稱、用途、origin）、必要相依服務、登入角色／方式、非機密背景摘要、預設 URL 與執行逾時。

- 建立時先訪談，使用者確認初始目標網站後才探索；未確認前禁止瀏覽探索。
- AI 詢問登入與必要前置資訊，提出結構化設定提案；QA 確認後才啟用／更新設定。取消提案不覆寫現行設定。
- 修改時帶入舊設定與背景；設定對話與測試對話分開。設定提案使用 revision 衝突檢查。
- 目標網站與登入／API／CDN 等必要相依服務分開；相依服務不是可任意驗測的目標。新增範圍由使用者確認，AI 不能自行放寬。
- 工具探索、草稿驗證及正式執行均強制範圍限制；涵蓋跳轉、popup、子資源及程式發出的網路請求。不能只靠 prompt 或單一 navigate 檢查宣稱隔離完成。
- 登入資料透過對話內專用機密欄位收集，普通訊息／description／skill／模型輸入只含角色與引用。執行時限定 Workspace／任務取得機密；日誌、工具結果、截圖及 trace 須處理洩漏風險，不能保證安全的證據應省略並說明。
- 平台權限尚不做 RBAC 介面，但測試、對話、執行、附件及機密皆以 Workspace 範圍讀寫，不可跨工作區引用。
- 不包含 Workspace 刪除、複製或多人協作功能。

## Worker skill-set

由 Server 指定對話類型、skill 版本及允許工具；Worker 載入對應的小型 skill，不建通用外掛平台。

| Skill | 輸入與交付 |
| --- | --- |
| Workspace 建立／修改 | 舊背景、設定提案與近期對話；受限探索、追問、輸出設定提案 |
| 測試建立／修改 | Workspace 快照、來源版本摘要、當前完整腳本與編輯週期對話；輸出候選草稿與驗證要求 |
| 驗收摘要 | 通過的 revision、完整腳本、對話背景與實際結果；輸出 description／背景摘要，不改腳本 |

Skills 共用既有 Playwright 操作 recipe。完整歷史持久保存，預設只傳摘要＋近期對話，按需檢索。網頁內容、對話資料與工具輸出不得變成系統指令。發佈資格、網站限制、機密存取與任務去重由程式強制執行。

## 最小驗收

一條主要流程：建立 Workspace 與確認範圍 → 以合成帳密探索 → 對話建測試 → 真實驗證與監看 → 摘要 → 人工發佈 → 一般模式正式執行 → 重開草稿續編 → 刪除草稿。另以第二個 Workspace 做一次資源／機密隔離檢查。

針對新風險補最小測試：過期 revision／摘要不能發佈、刪除後晚到結果不能復活草稿、禁止跨範圍連線、機密不進模型與附件。沿用 M1–M6 無關的既有證據，不重跑全套。
