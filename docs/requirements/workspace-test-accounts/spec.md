# Workspace 逐站登入驗證與測試帳號

QA 建立或調整 Workspace 背景時，可針對每個目標站台決定本次要測的流程。每個涵蓋登入後流程的站台，都須至少有一組測試帳號在該站登入成功，Workspace Admin 才能確認完成設定。第一版支援帳密表單，SSO、MFA 等登入能力另案規劃。

## 訪談與逐站設定

1. AI 釐清驗測目的、目標站台、用途、背景與排除範圍，逐站詢問 QA 要測訪客流程、登入後流程，或兩者皆測。尚未回答時保留待釐清。使用者確認網站範圍後，才可開始探索。
2. 只測訪客流程時，直接記錄該站的選擇，即使頁面有登入按鈕也可略過帳號。涵蓋登入後流程時，AI 詢問登入入口、登入方式、所需角色，以及登入後可觀察的成功條件。
3. AI 邀請使用者提供一組或多組帳號，並引導至專用機密欄位輸入帳密。名稱、角色與適用的驗證項目可在訪談中描述。登入服務若位於其他 origin，依既有範圍確認流程列為登入相依服務。
4. AI 透過平台在已核准的範圍內啟動驗證。Worker 從無既存登入狀態的瀏覽器工作階段，以指定帳號登入，並在**目標站台**檢查可區別訪客與登入者的結果，例如可開啟受保護頁面並看見帳戶選單。即使兩站共用登入服務，也各自記錄結果。
5. Server 核對每一站的選擇及有效驗證結果。當所有站台都符合門檻，Workspace Admin 可確認套用。尚有缺項時，保留提案，逐站顯示原因及下一步。修改既有 Workspace 期間，已確認版本持續生效至新提案套用。

| 本次站台範圍 | 可確認條件 | 未達條件時的操作 |
| --- | --- | --- |
| 尚待釐清 | QA 明確選定測試範圍後重新判定 | 回到該站的訪談問題 |
| 只測訪客 | 已選定訪客流程 | 可直接進入整體確認 |
| 含登入後流程 | 該站至少一個帳號有有效成功紀錄 | 補帳號、修正入口或成功條件後重試；尚未支援的登入方式顯示待驗證與原因 |

錯誤密碼、僅送出表單、仍停在登入頁或只能開啟公開頁面，都不能產生成功紀錄。成功結果綁定 Workspace、目標站台、帳號及當次驗證使用的設定與憑證版本。Server 在套用時再次核對，取消、重送或晚到的舊結果均不得讓提案誤過關。

## 管理帳號與撰寫腳本

- 每組測試帳號具有穩定識別碼、適用站台、顯示名稱、角色、用途說明及逐站驗證狀態。多組帳號可以具有相同角色。Workspace Admin 可維護角色與用途，例如將兩個會員帳號分別標為「建立訂單」及「驗證他人訂單不可見」。
- 修改名稱或用途後，新任務取得更新後的說明，既有成功紀錄仍有效。更換帳密、登入入口、適用站台或成功條件時，受影響的帳號與站台須重驗。若該站仍有另一組有效帳號，仍符合逐站門檻。
- 內建、Vercel、Pi 與 MCP 接單 Agent 從任務快照取得獲授權帳號的識別碼、站台、名稱、角色、用途與驗證狀態，以及登入工具的用法。MCP 互動模式依其 Workspace 授權與瀏覽器租約取得相同資訊。Agent 依測試目的選用具體帳號，以識別碼交由平台登入；訪客案例使用未登入的瀏覽器狀態。若測試要求兩個不同身分，須選兩組不同帳號；缺少適用帳號時，說明缺少的角色或用途並請 QA 補充。
- 帳號說明依 Harness 視為資料。工具每次使用都核對 Workspace、站台、任務或租約授權。帳密只經專用機密管道交給可信登入工具，模型輸入、腳本原始碼、對話、監看及報告均須遮蔽機密。
- 既有設定缺少逐站選擇或驗證證據時，重新設定應顯示待釐清或待驗證。沿用既有腳本的角色引用與歷史快照；不得依同名角色猜測或重新指派帳號。

## 驗收情境

| 編號 | 操作與預期結果 |
| --- | --- |
| A1 訪客 | 有登入入口的公開站選「只測訪客」，零帳號也能完成設定。尚未選定範圍時，需先補答。 |
| A2 多站 | 設定一個訪客站及兩個需登入站。第一站帳號登入成功、另一站僅送出表單時，仍保留草稿；第二站也通過受保護頁面檢查後，管理員可確認。共用登入服務時亦同。 |
| A3 失敗與重試 | 密碼錯誤或需要 MFA 時顯示對應原因，重開仍可接續。修正帳密表單設定後可重驗；舊 attempt 的晚到成功不可覆寫新結果。 |
| A4 管理 | 管理員可編輯兩個同角色帳號的用途，一般成員寫入遭拒。改說明後新任務讀到新值；輪替一組帳密只使相關證據失效。 |
| A5 選用與隔離 | 建立訂單與驗證其他會員不可見的腳本選用兩個指定帳號。逐入口驗證授權放行、未授權帳號或錯站拒絕、無適用帳號時回報缺項，以及合成帳密未出現在模型輸入與輸出產物。 |
| A6 相容 | 舊 Workspace 可開啟修改，既有角色引用仍指向原帳號。缺少逐站證據的提案須補驗才能套用，過期 revision 不能覆蓋已確認設定。 |
